Privacy Policy

Last updated: September 30, 2026

Shop Helper is a personal tool operated by Emin Yüksel, an individual seller based in Ankara, Turkey. It is used only to manage listings in my own Etsy shop. This page explains what data the app accesses and how it is handled.

Data the app accesses

Through the official Etsy Open API v3, the app accesses only my own shop's listing data:

  • titles, descriptions, and tags;
  • prices;
  • images and digital files;
  • listing stats.

Where data is stored

Data the app retrieves is stored locally on my own computer.

What is never collected

The app never collects buyer data or order data.

Sharing and selling

No data is sold or shared with third parties.

Credentials

The OAuth tokens that let the app connect to Etsy are stored only on my own computer. They are used only to access my own shop.

This website

This website is a static page hosted on GitHub Pages. It does not use cookies, analytics, or trackers, and it does not load any external resources. GitHub may process basic technical information (such as IP addresses) as part of hosting; see GitHub's own privacy statement for details.

Questions and deletion requests

If you have questions about this policy, or would like data related to you to be deleted, please email me at eminyuksel97@gmail.com. I will respond as soon as I can.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new "last updated" date.
