Etsy authorization finished

One more step to connect Shop Helper to the shop.

  1. Copy the full URL from the browser's address bar.
  2. Paste it into the Shop Helper command-line tool.

Shop Helper reads the authorization code from the URL.

The code in this URL expires within minutes, and it is useless without the secret verifier kept on my computer.

If the URL contains error= instead of code=, authorization didn't complete. Start again from Shop Helper.
