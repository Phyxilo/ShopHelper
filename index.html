Shop Helper

A personal tool for managing listings in my own Etsy shop.

About me

I'm Emin Yüksel, an individual seller based in Ankara, Turkey. I built Shop Helper to manage my own shop.

What Shop Helper does

Shop Helper works only with my own Etsy shop. It:

  • creates draft listings in my shop;
  • uploads listing images and digital files;
  • updates or deactivates my own listings;
  • reads my own shop's listings to keep them in sync.

How it works

Shop Helper creates new listings as drafts. I review every listing before it's published.

What Shop Helper doesn't do

  • It doesn't access other shops' data.
  • It doesn't read orders or buyer information.
  • It doesn't collect data from Etsy's website pages.
  • It isn't offered to or used by anyone else.

It uses only the official Etsy Open API v3.
